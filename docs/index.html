Claude Usage Bar

A Chrome extension that adds compact Claude usage, reset, context, and pace indicators directly inside claude.ai.

Privacy Policy Support

What it does

  • Shows Claude usage and reset information in the chat composer.
  • Estimates context usage for the active conversation.
  • Offers optional local weekly learning for better pace estimates.

Privacy summary

  • Runs only on https://claude.ai/*.
  • Does not send user data to the developer.
  • Does not use analytics, ads, telemetry, or tracking.
  • Weekly learning history is off by default and opt-in.
Claude Usage Bar is not affiliated with Anthropic. For details about data access, storage, and user controls, read the privacy policy.
