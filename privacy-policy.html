Privacy Policy for Claude Usage Bar

Last updated: May 26, 2026

Claude Usage Bar is a Chrome extension that displays usage, quota, reset, context, and pace information while using Claude at https://claude.ai. Claude Usage Bar is not affiliated with Anthropic.

Information the extension accesses

Claude Usage Bar runs only on https://claude.ai/*. To provide its usage display features, the extension may access:

  • Visible Claude page content, including conversation text shown in the active Claude page.
  • Claude usage information, such as usage percentages, reset times, message counts, and quota information.
  • Claude conversation metadata used to estimate context window usage, token usage, cache timing, and usage history.
  • Extension settings, such as display preferences for the usage bar, context ring, pace display, and overlay visibility.

Claude account session

The extension may send requests directly to https://claude.ai using your existing logged-in Claude browser session. These requests are used only to retrieve usage and conversation-context information needed for the extension's user-facing features.

Claude Usage Bar does not read, store, copy, sell, or share your Claude cookies, passwords, authorization headers, or authentication tokens. Authentication is handled by the browser and Claude's own website.

Information processed locally

Claude Usage Bar may read visible Claude conversation content in your browser to estimate token and context usage. This processing happens locally in the extension. The extension is designed not to store the full text of your Claude messages, prompts, responses, uploaded file contents, cookies, authorization headers, or tokens.

Information stored locally

Claude Usage Bar stores limited information locally using Chrome extension storage (chrome.storage.local). This may include:

  • Usage estimates and sanitized usage snapshots.
  • Message counts and token/context estimates.
  • Usage history used to display trends or pace information.
  • Your Claude organization ID, used to avoid repeated lookup requests.
  • Extension display settings and preferences.

Information transmitted externally

Claude Usage Bar does not send your data to the developer's servers. The extension does not use third-party analytics, advertising, telemetry, or tracking services.

The only external requests made by the extension are requests to https://claude.ai, used to provide usage-related features inside Claude. These requests are sent directly to Claude/Anthropic and are subject to Anthropic's own privacy practices.

How information is used

Information accessed by the extension is used only to provide Claude Usage Bar's user-facing features, including usage percentages, reset timing, context estimates, cache timing, and local usage history.

The extension does not use user data for advertising, profiling, resale, unrelated analytics, or any purpose unrelated to the extension's single purpose.

Data sharing and sale

Claude Usage Bar does not sell, rent, trade, or share user data with third parties. The developer does not operate a backend server that receives user data from the extension.

Limited Use disclosure

Claude Usage Bar's use of information received from Chrome extension permissions is limited to providing its single user-facing purpose: displaying Claude usage information inside Claude. The extension does not transfer user data except as necessary to provide that purpose, does not use user data for advertising, and does not allow humans to read user data.

User control and deletion

You can remove locally stored extension data by uninstalling the extension or clearing the extension's stored data in Chrome. You can also disable the extension at any time from Chrome's extension settings.

Security

Requests made by the extension are sent over HTTPS. Locally stored data remains in Chrome's extension storage on your device.

Changes to this policy

This policy may be updated if the extension's behavior changes. Updates will be posted on this page with a revised "Last updated" date.

Contact

For questions about this privacy policy, contact the developer through the project repository at https://github.com/Ryoshkenn/Claude-Usage-Bar/issues.
